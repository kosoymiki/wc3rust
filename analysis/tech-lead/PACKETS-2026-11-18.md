# THICK PACKETS — wc3rust lanes (2026-11-18, tech-lead)

Every lane reads its own section. This document SUPERSEDES the thin dispatch that

## COMMON CONTRACT (applies to every lane)

- **Goal + invariants:** the lane's goal below; invariants: no placeholders/stubs,
  no un-tested merges, no silent fallbacks, no edits outside OWNER_PATHS, data
  from shipped tables only, determinism preserved (`state_hash` on save/load).
- **Mechanism first:** for every defect, name the file:line that causes it before
  patching; reproduce with a failing test; then one minimal fix; then re-verify.
- **OWNER / READ_ONLY:** exact path lists per section. A conflict is resolved by
  the tech-lead, never by editing the other lane's file.
- **Build discipline:** cargo ONLY via `scripts/h2-cargo` (flock). Never kill a
  running build. Never run two cargo commands in parallel.
- **Evidence contract:** every claim in the final report carries a command and its
  rc, a test name, a file path, or a measured number. `observed | inferred |
  unknown` labels. No "should work".
- **Phase plan:** census → reproduce → fix → test → measure → report. Checkpoint
  the ledger after each phase; capture/experience at close; close with
  `result`, `h2_ids_json`, terminal verification `ok:true`.
- **Report format:** Goal | Actions | Evidence | Result | Risks/Next |
  H2_PERSISTED (capture/experience/ledger) | SESSION_CLOSED.
- **Intervention:** if blocked >20 min or the fix needs another lane's file, stop
  and report the exact symptom + proposed patch; do not sit on it.

# GOAL 2026-11-18 — acceptance basis = Orc01 (first RoC orc campaign)

Operator directive: from now on the whole build is judged on the FIRST ORC
CAMPAIGN CHAPTER OF REIGN OF CHAOS (`Maps\Campaign\Orc01.w3m`, loaded from the
operator's MPQ). A lane is not done until its layer is correct *on that map*.
A technical demo is not accepted; every corner must be polished.

## Why this map is the integration gate (mechanism)

Orc01 exercises, in one run: campaign chapter load from the MPQ, JASS boot with
quests and transmissions, scripted camera and fades, orc roster units and their
animations, terrain/cliffs/water/doodads of that tileset, day/night lighting,
ambience and voice lines, the HUD quest log and command card, save/load of a
scripted (non-melee) match. Anything broken in any layer shows up here.

## Per-lane Orc01 checks (add to the lane's own acceptance)

- 501 SIM: load Orc01, run 3000 ticks headless; assert: units present with the
  expected orc defs, orders execute (move/attack/hold), no panic, `state_hash`
  stable across save/load, quest completion events fire.
- 502 RENDER: capture Orc01 at 2414x1080 at dawn/noon/dusk; assert: no black or
  missing terrain layers, cliffs/water/doodads of that tileset render, FoW three
  states, day/night curve visible in the means.
- 503 CAMPAIGN: `CAMPAIGN_LOAD source=mpq path=Maps\Campaign\Orc01.w3m`; quests
  with real TRIGSTR text; camera keyframes (>=4, monotone t, max jump <=400);
  transmissions with speaker; fades; mission completes -> next chapter unlock.
- 504 HOST: install the APK, cold start, play Orc01 for 5 minutes: fps average,
  PSS <=350 MB, one background/resume cycle, first tap after start issues a move.
- 507 CONTENT: every unit that appears in Orc01 resolves to a real def + model +
  icon; list any `unknown_def` skips from the load log and close them.
- 508 AUDIO: Orc01 ambience/voices/music: no `AUDIO_EVENT missing`, ack/attack/
  death lines fire, PCM <=64 MB over the 5-minute run.
- 509 ASSETS: Orc01 loads with War3.mpq (+War3x for TFT tables) and zero missing
  files in the log; campaign map found inside the MPQ, not copied by hand.
- 510 GATES: the Orc01 smoke is part of the gate (headless load + 3000 ticks).
- 511 ABILITIES: every ability used by Orc01's heroes/units resolves (typed or
  DataOnly with a reason); no silent no-op in the mission.
