## COMMON CONTRACT (every lane)

- **Goal:** a playable orc campaign on the phone, judged layer by layer. A lane is
  done only when its layer is correct *on Orc01/Prologue01* with the artifact the
  section names.
- **Invariants:** no stubs/TODO/deferred work; no silent fallbacks where the data
  exists; data only from the shipped tables/archives; determinism (`state_hash`)
  preserved; no edits outside OWNER_PATHS; single-slot builds via `scripts/h2-cargo`
  only (FIFO queue; `H2_CARGO_PRIORITY=1` for the critical path; never kill another
  lane's build).
- **Mechanism first:** for every defect, name `file:line` before patching, reproduce
  with a failing test or a logged device line, then one minimal fix, then re-verify.
- **Evidence contract:** every claim carries a command + rc, a test name, a file
  path, or a measured number. Label `observed | inferred | unknown`.
- **Report form:** Goal | Actions | Evidence | Result | Risks/Next | H2_PERSISTED
  (capture/experience/ledger) | SESSION_CLOSED. Close via `harness2_monitor close`
  with `h2_ids_json`.
- **Intervention:** blocked >20 min or needing another lane's file → stop and say
  exactly what you need; never edit the other lane's file.

   with the same `state_hash`.

ACCEPTANCE: `cargo test -p wc3-sim` rc=0; the seat-4 visibility test named in the
report; save/load digest unchanged for a 2-seat melee save.
