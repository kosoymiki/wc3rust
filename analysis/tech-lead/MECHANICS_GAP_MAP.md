## What this means for a 10/10 port

The decompilation layer is complete and machine-checkable: 7,451 named files /
543,237,719 bytes with 0 read failures, 812 units, 812 weapons, 763 abilities,
273 items, 79 misc tables, 44 maps / 19,420 script functions. The gap is in
**execution coverage**, and the map above names it precisely:

- Every economy, production, movement, pathing, combat-table, spawn and HUD
  mechanic is ported and tested.
- The largest remaining blocks are the 750 ability effects that have data rows
  but no executable port, hero skill spending/revive, item drops, creep rewards,
  cinematic playback of the 44 maps, and the campaign/multiplayer/save layers.
- Each PORTED row has a named test file; a mechanic without a test is listed as
  PARTIAL by definition, so this table cannot overstate coverage.
