5. **Unimplemented JASS natives** — the VM records every fallback call; the census is in `SCAN.md`. These are platform/render/audio natives, not syntax gaps; map `main` still completes 44/44.
6. **22 skin paths absent** — mostly `.mdl` UI models stored as `.mdx` in TFT or not in the RoC base; the resolver tries the `.mdx` fallback and reports the rest.
