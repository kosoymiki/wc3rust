# 507 — CONTENT DATA lane report (2026-11-18)

Acceptance basis changed mid-lane to **Orc01** (`PACKETS-2026-11-18.md`,
"GOAL 2026-11-18"). This report covers both the original per-table census and
the Orc01 gate.

## Goal

Prove the sim content tables against the shipped SLKs (units, buildings,
upgrades, items, abilities, destructables), close every gap with the existing
generators (never hand-typed numbers), and make Orc01 load with every unit it
places resolving to a real def + model + icon.

## What was wrong (observed, before)

| table | source rows | rows in our data | melee-reachable missing | campaign-placed missing |
|---|---|---|---|---|
| units (`UnitBalance.slk`) | 813 | 551 | 2 (`hatw`, `uzg2`) | 97 |
| upgrades (`UpgradeData.slk`) | 89 | 89 | 0 | — |
| items (`ItemData.slk`) | 273 | 273 | 0 | — |
| abilities (`AbilityData.slk`) | 763 | 763 | 0 | — |
| destructables (`DestructableData.slk`) | 246 | 246 | 0 | — |

Coverage defects behind those numbers:

1. `hatw` (Arcane Tower) and `uzg2` (Frost Tower) are `Upgrade=` targets of the
   Scout Tower / Ziggurat, but the curated building lists did not name them, so
   the third human tower and the second ziggurat tier had no def at all.
2. No campaign unit was a def: `Othr` (Thrall) and `Ocbh` (Cairne) — the two
   heroes Orc01 places — were dropped as `unknown_def`.
3. Every creep def carried `model_present: false` and `icon: ""` (327 rows): the
   generator guessed the model from the editor comment and never read the icon.
4. Every neutral building (`EXTRA_DEFS`, 103 rows) carried `model_present: false`
   and `icon: ""`, and the tavern `ntav` was emitted twice (roster + extras).
5. Model resolution ignored `unitUI.slk file`, the column that actually carries
   the shipped model path (`units\orc\HeroTaurenChieftainCIN\...`).

## What changed (mechanism, all generator-driven)

* `analysis/agent-sim/gen_content_census.py` (new) — the census itself.
  Reads the SLKs, the profile texts, and all 88 shipped campaign maps
  (RoC `.w3m` = 512-byte `HM3W` header + MPQ, read with `mpyq`), plus each
  map's `war3mapUnits.doo`, `war3map.j` and `war3map.w3u`. Writes
  `CONTENT-GAPS-2026-11-18.md`, `content-census-2026-11-18.txt`,
  `campaign-map-ids.json`, and the generated id block inside
  `crates/wc3-sim/tests/content.rs`. Idempotent (byte-identical on re-run).
* `gen_roster.py`:
  * `ui_model()` / `icon_of()` — model from `unitUI.slk file`, icon from `Art=`.
  * `upgrade_buildings()` — every `Upgrade=` target of a curated building is
    emitted as `TECH_DEFS` (`hatw`, `uzg2`), derived, not listed.
  * `campaign_order()` — campaign-placed ids from `campaign-map-ids.json` are
    emitted as `CAMPAIGN_DEFS` (84 rows), so `def_of` resolves them while the
    melee roster, build menu and every `UnitDefId` index stay untouched.
* `gen_creeps.py` / `gen_neutrals.py`: same `unitUI.file` model source and
  `Art=` icons; `ntav` is no longer duplicated into `EXTRA_DEFS`.
* `data.rs`: `def_of`/`def_at`/`def_index` chain `TECH_DEFS` + `CAMPAIGN_DEFS`
  last (no shipped index moves).
* `tests/content.rs`: `content.<table>.complete` for all six tables plus
  `content.orc01.complete`, driven by the generated census block.

## Orc01 (acceptance)

Map: `analysis/war3_full/Maps/Campaign/Orc01.w3m`, 185 `war3mapUnits.doo`
records.

* 30 unit ids with SLK rows — all resolve, all with `model_present` and an icon
  (`Othr`, `Ocbh`, `ogru`, `ohun`, `otau`, 25 neutral creeps/structures).
* 4 map-object ids — `oC03 ← otau`, `nC08 ← ncnt`, `nC09 ← nct1`, `nC10 ← nct2`
  parsed from the map's `war3map.w3u` (parse consumes the file exactly; the only
  overrides are `unam`/`unsf`/`usca`/`uclb`/`uhpm`, never `umdl`/`uico`), so the
  base def supplies the model and the icon.
* 3 items (`hlst`, `shea`, `whwd`) and 2 destructables (`BTtw`, `LTcr`) resolve.
