# Asset provenance and redistribution boundary

- `source/generate_assets.py`: original procedural artwork authored for this asset pack.
- `console/`, `minimap/`, `portrait/`, `selection/`, `commandcard/`, `resources/`, `topbar/`, `tooltip/`, `cursor/`, `build/`, `controlgroups/`, `menus/`, `atlases/`: generated outputs from that script.
- `fonts/`: DejaVu font files; see `DEJAVU-FONTS-LICENSE.txt`.
- No original Warcraft III extracted UI textures, BLP/TGA files, Blizzard command icons, DragonUI texture files, DragonUI Lua/XML, or donor project code are included.
- The reference archive is not copied into the output pack. This keeps the delivery's redistributable asset surface clear.
