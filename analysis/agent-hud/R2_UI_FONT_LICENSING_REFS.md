## 2. Fonts — what is actually inside the MPQ

### 2.1 The UI face is **Nimrod MT**, not Friz Quadrata

`Fonts/FRIZQT__.TTF` is named after Friz Quadrata but its `name` table says:

| name ID | value |
|---|---|
| 0 copyright | `Digitized data copyright The Monotype Corporation 1991-1999. All rights reserved. Nimrod is a trademark of The Monotype Corporation…` |
| 1 family | **`Nimrod MT`** |
| 4 full name | `Nimrod MT` |
| 7 trademark | `Nimrod is a trademark of The Monotype Corporation…` |
| 13 licence | see 2.2 |

`Fonts/NIM_____.ttf` is the **same face** (identical metrics and name table) — a duplicate. This corrects `FONT_TEXT_METRICS.md` (§8 below) and any note that called the UI font "Friz Quadrata".

### 2.2 The Monotype licence text shipped in the file (name ID 13, verbatim excerpt)

> NOTIFICATION OF LICENSE AGREEMENT
> This typeface is the property of Monotype Typography and its use by you is covered under the terms of a license agreement. You have obtained this typeface software either directly from Monotype or together with software distributed by one of Monotype's licensees.
> This software is a valuable asset of Monotype. Unless you have entered into a specific license agreement granting you additional rights, your use of this software is limited to your workstation for your own publishing use. **You may not copy or distribute this software.**

Consequence: the face is redistributable only under Blizzard's own agreement with Monotype, i.e. **inside the user's Warcraft III installation**. We may rasterise it at runtime on the user's device (the game already does); we may not bundle, embed, subset, convert to atlas PNG, or commit it.

### 2.3 The other five faces

| File | Family (name table) | Copyright (name table) | Use |
|---|---|---|---|
| `DFHeiMd.ttf` | `DFKGothic-Md` | `(c) Copyright DynaLab Inc. 1992-1996`, `Trademark by DynaLab Inc.` | CJK |
| `dffn_b31.ttf` | (DynaLab, mojibake name) | `(C)Copyright DynaLab Inc. 1997` | CJK |
| `dfst-m3u.ttf` | `Song Light` | `Private data generated by Bitstream TrueDoc (TM)` | CJK |
| `tt5500m_.ttf` | `SquareGothicMd BT` | `Copyright 1990-1997 Bitstream Inc. All rights reserved.` | CJK |
| `NIM_____.ttf` | `Nimrod MT` (dup) | Monotype, as above | spare |

None of these are open fonts. All five are commercial faces bundled by Blizzard for its locales.

### 2.4 Why this matters for our atlas

`FONT_TEXT_METRICS.md` §5 specifies a raster atlas. The atlas **is a copy of the font's outlines** — so an atlas built from `FRIZQT__.TTF` inherits the Monotype restriction. Two legal production paths:

1. **Runtime atlas from user data** (recommended): rasterise on device from the MPQ font the user owns, keep the atlas in RAM only, never write it to disk/save state. This is what the game itself does.
2. **OFL substitute** for anything that must be bundled (menus outside the game, launcher, web): see §3.

## 3. OFL route for bundled text

If any UI must render without user data (installer, launcher, error screen, store page), it needs its own font under a redistributable licence.

SIL OFL 1.1, quoted from `choosealicense.com/licenses/ofl-1.1/` (2026-11-13):

> … bundled, embedded, redistributed and/or sold with any software provided that any reserved names are not used by derivative works

and from `scripts.sil.org/OFL` (2026-11-13):

> … bundle them in apps or software subject to certain conditions
> … may require a name change to respect any declared Reserved Font Names (RFNs)

So: OFL allows bundling **with** the licence text, copyright notice, and no use of Reserved Font Names in modified versions. Modifying the font (subsetting counts) is allowed under the same conditions.

Selection criteria for a substitute (measured from Nimrod MT in `FONT_TEXT_METRICS.md` §3): cap ≈ 0.739 em, x-height ≈ 0.539 em, line ≈ 1.391 em, tabular digits 0.5 em, Cyrillic coverage. Candidate families to evaluate (**licence and coverage to be verified per file before bundling** — do not treat this list as cleared):

| Candidate | Licence (to verify) | Why |
|---|---|---|
| PT Serif / PT Sans | OFL (ParaType) | Cyrillic-first design, humanist serif close to the WC3 look |
| Noto Serif / Noto Sans | OFL | widest coverage (Cyrillic + CJK) |
| Cinzel | OFL | inscriptional caps for titles only |
| EB Garamond | OFL | body serif alternative |

The substitute needs a size compensation, because cap heights differ: `px_substitute = px_nimrod × (0.739 / cap_substitute)`. Fill that constant in only after measuring the chosen TTF.

You may not transfer your rights and obligations to use the Platform." | a private build that reads the operator's own data sits inside the contemplated use; a commercial product using the data does not |
| Reverse engineering | "…reverse engineer, derive source code from, modify, disassemble, decompile, or create derivative works based on or related to the Platform." (prohibited list) | the EULA prohibits RE as a matter of contract, independent of copyright; the project's clean-room/no-distribution posture is what keeps this a private-risk question, not a distribution one |

This upgrades `docs/LEGAL.md` §7 from "reported/contested" to **quoted primary text** for the assignment clause. It is still not legal advice, and the doc's own disclaimer stands.
